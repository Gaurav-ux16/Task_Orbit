TaskOrbit API

Workflow-aware project management REST API · served as a static resource by Express (express.static)

Authentication

Sign in with POST /api/auth/login. The server answers with an HttpOnly session cookie (to_sid) and a CSRF token. Send the token in X-CSRF-Token on every POST, PATCH and DELETE.
